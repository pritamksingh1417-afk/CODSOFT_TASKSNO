# 🧮 Calculator

A simple GUI-based Calculator application built with Python and Tkinter.

## ✨ Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal number support
* Clear button
* Result display
* Division by zero error handling
* Invalid input error handling
* Simple graphical user interface

## 🛠️ Technologies Used

* Python
* Tkinter
* Tkinter MessageBox
