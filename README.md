# 📝 Smart To-Do List

A modern GUI-based To-Do List application built with Python and CustomTkinter.

## ✨ Features

- Add tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Search tasks
- Filter tasks by status
- Task statistics
- Automatic task saving
- Automatic task loading
- Keyboard shortcuts
- Modern graphical user interface

## 🛠️ Technologies Used

- Python
- CustomTkinter
- JSON
- Tkinter MessageBox
