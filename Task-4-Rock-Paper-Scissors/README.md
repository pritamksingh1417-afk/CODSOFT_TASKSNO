# 🎮 Rock Paper Scissors

A simple GUI-based Rock Paper Scissors game built with Python and Tkinter.

## ✨ Features

* Rock, Paper, and Scissors choices
* Random computer selection
* Winner determination
* Player and computer score tracking
* Result display
* Reset game button
* Simple graphical user interface

## 🛠️ Technologies Used

* Python
* Tkinter
* Random Module
