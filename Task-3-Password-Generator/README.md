# Password Generator

A simple password generator made using Python and CustomTkinter.

## Features

- Generate random passwords
- Select password length
- Uppercase letters
- Lowercase letters
- Numbers
- Special characters
- Copy password to clipboard
- Password strength indicator
- Dark and light mode

## Technologies Used

- Python
- CustomTkinter
- Secrets
- String
